2026-10-12。用户授权继续中断实验并解决内存不足。代码改动发生于原训练已退出之后；原模型、源码身份与故障证据均保留。

## 故障与处理

规则组在第 890 回合保存完整断点时被内核因主机 RAM 耗尽杀死，匿名常驻内存约 23.76 GiB。第 881～890 回合已经有日志和数组，完整断点仍在第 880 回合、累计 SAC=26495。完整断点中的成功经验不断累积；旧 PyTorch 保存路径把 NumPy 数据集中写入 pickle 内存缓冲区，产生额外峰值。

增加 `finite_contact/memory.py`，对观测各数组按原 dtype、shape 和字节无损 zlib 压缩，仅在组成批次时解压。网络收到的数值完全一致；回放顺序、所有成功经验、动作、奖励、终止标记和抽样均保留。完整断点采用 pickle 协议 4，仍为自包含文件。流式读取旧断点的 pickle，避免另建整个多 GB 输入缓冲区；Tensor storage 以 CPU 重建。旧断点迁移在 22 GiB 虚拟地址空间上限的 CPU 进程中执行。

恢复时逐行处理旧 JSONL，避免一次把数百万通信事件读成 Python 字典列表；归档记录恢复边界、额外回合和更新数，并复制尚未进入断点的地图数组。

## 机器配置

配置文件：[rtx3090_32gb.json](profiles/rtx3090_32gb.json)。RTX 3090 24 GiB 显存、单 worker、两个 Torch CPU 线程、batch=16、embedding=64、回放 12000、成功地图 1000 槽。显式保留原 Actor／Q／温度学习率、两机器人、地图顺序与各组新增 20000 次 SAC 的预算；通信头与上下文继续冻结。所有以后通过 `finite_contact_scale.py` 新建的 1000 图实验默认使用该内存配置。

续训环境另外设置 `MALLOC_ARENA_MAX=2`，限制分配器 arena 数量，BLAS 线程为 1。目标训练 RSS 为 8 GiB 以内；实际峰值写入每组 `status.json` 的 `peak_rss_mib`，以真实进度快照为准。内存配置没有缩小网络、删减地图或降低成功门槛。
