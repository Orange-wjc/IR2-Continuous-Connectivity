# 收尾抽样的另外两个适应种子复现

日期：2026-10-12；分支 `research/finite-contact-exploration`；统一使用conda `ir2_train`。本计划在新训练开始前固定，后续结果另行追加。

## 目的和范围

上一轮seed=2是根据已有较弱表现选择的探索试验。pooled继续训练的FIFO／规则／学习在20开发图均成功18张，map_tail为19／20／20；候选学习平均120.694秒，比同样20/20的候选规则快17.57%。但map_tail的FIFO训练监测从9/10降到6/10，不能仅据开发改善认定稳定性解决。

本轮仅做seed=1、3的固定条件复现，不改抽样配比、不改奖励、网络、感知、通信、完成标准或学习率。全部基线使用同样训练修正和预算。保留seed=2的原始结果，明确它是先行探索种子；不把三种子称作三条独立预训练链路，不把同一20开发图的60次评估当60张独立地图。

## 事前固定实验

- 源模型来自已完成的原三种子移动适应：seed=1位于 `experiments/multimap_joint_20261012_seed1/`，seed=3位于 `experiments/multiseed_20261012/seed_3/`。各组从自己的完整latest复制网络、Adam、普通回放和自身成功缓存；episode=100、SAC=10895、head=5000。
- 每个种子做pooled／map_tail × FIFO／规则／学习，共六组；两个新种子共12组。每组在同一原100张训练图上再完整遍历一次，global episode 101～200，每完整sampled地图后20次真实SAC，新增2000、累计12895。新增总预算24000；已有seed=2不重训。
- 保持Actor=1e-5、Q／温度=1e-4、辅助权重1、回放容量12000。普通SAC抽样不变；通信头及上下文冻结。map_tail按已有成功图等概率，50%全路线／50%最后四分之一物理时间后缀，包括跨越75%时刻的决策。
- 两机器人；simple_rooms_v1，数据种子20261011，100/20/20划分；每机99%、256秒、2048 B/s/发送方、距离65不变。全实验最多三个GPU worker，每worker2小时上限只作异常保护，未完成预算不参加固定终点比较。
- 每对使用同样地图调度和逐回合随机种子公式，初始完整状态相同。不同抽样导致后续随机数消耗变化属于该处理效应；不声称训练轨迹一直相同。
- 在追加0／50／100图时监测原训练前10图，仅用于学习曲线；终点只评估原20开发图，不按中途开发成绩选模型。测试策略执行仍为0。
- 全部固定终点和训练监测退步都保留；先看完成数，再看失败按256秒计的平均时间、覆盖、同步缺口。单列每种子的map_tail相对pooled得失，也报告两种抽样下学习相对规则的配对差异。三种子均值±样本标准差仅作描述；不事后改预算追逐更优终点。
- 对两新种子分别审计完整训练／监测／开发轨迹、真实优化器步数、头冻结、源哈希、成对首次轨迹与地图调度；新增主执行预期1800条轨迹，合并先行种子为2700条执行轨迹，重复初始监测不是独立样本。

## 实现和恢复

`finite_contact_stability.py`仅将准备阶段的seed=2硬编码改为从源配置推断，并继续要求同一组六组配对源配置一致；实际训练、奖励、抽样实现未改。新入口 `finite_contact_stability_replication.py`使用原worker和最多三个进程队列，执行两种子并汇总三种子固定终点。旧seed=2输出和已保存执行源码不覆盖。

```bash
/home/wyz/anaconda3/envs/ir2_train/bin/python finite_contact_stability_replication.py \
  --output experiments/stability_replication_20261012 --device cuda --workers 3
```

同一实验恢复加 `--resume`。后台使用独立会话启动，PID、命令和时间记录在输出目录。已完成组跳过，未完成组从完整地图边界恢复；初始化未完成时归档，不把部分checkpoint当作有效模型。所有真实重做计算需单列。

每种子固定终点 `seed_<1或3>/<pooled或map_tail>/<组>/final.pth`，完整续训状态为同组latest.pth。输出原始地图、源码、轨迹、通信、更新与开发失败分析，保留原始及小型汇总证据。默认训练抽样仍pooled；候选仅显式启用，不因单次正结果自动改默认。
